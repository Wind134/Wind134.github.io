02

确认文章信息

这些字段决定文章 URL、分类目录和图片目录。

文章将写入 _posts/分类/YYYY-MM-DD-slug.md
图片将写入 assets/img/posts/slug/

为什么需要选择本地目录？

GitHub Pages 是静态网站，不能直接修改仓库。这里使用浏览器的文件系统授权，只写入你主动选择的本地仓库；写入完成后仍由你检查并执行 Git 提交。
